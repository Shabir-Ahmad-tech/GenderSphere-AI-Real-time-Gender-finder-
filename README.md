# GenderSphere AI 👤✨

**A High-Accuracy, Minimalist Real-Time Gender Analysis System.**

GenderSphere AI is a professional-grade computer vision application built with Python and Streamlit. It uses advanced deep learning (DeepFace & Facenet) and geometric face alignment to provide ultra-stable, real-time gender detection. It's designed to be sleek, fast, and remarkably accurate.

---

## ✨ Key Features
- 🎯 **90%+ Accuracy**: Powered by Facenet models and 5-point face alignment.
- ⚡ **Zero Lag**: Asynchronous background processing ensures a perfectly smooth camera feed.
- 🌑 **Sleek UI**: Minimalist GitHub-inspired dark mode interface.
- 🧊 **Stability Engine**: Uses confidence filtering and temporal voting to prevent result "flickering."
- 💇 **Context-Aware**: Advanced cropping logic accounts for hair and jawline for superior gender analysis.

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Webcam

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Shabir-Ahmad-tech/GenderSphere-AI-Real-time-Gender-finder-.git
   cd GenderSphere-AI-Real-time-Gender-finder-
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Running the App
```bash
streamlit run app.py
```
